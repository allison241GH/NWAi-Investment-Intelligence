## ② The 7-Stage Deal Pipeline + Member Writes at Every Stage

### Pipeline flow &nbsp;·&nbsp; **[✓ Live]**

```
📥 Inbox  ›  🔍 Screening  ›  🤝 Scout/Intro  ›  🔬 Diligence  ›  📋 DD Report  ›  ✅ Decision  ›  📝 Memo
 /screen     /screen          /scout              /diligence         /dd-report      /decision      /memo
```

### Member writes lane &nbsp;·&nbsp; **[🔨 Build · V1]**

Social deal card actions at every stage:

| Stage | Member writes |
|---|---|
| Inbox | match alert · I know this founder |
| Screening | quick reaction · I know this space |
| Scout / Intro | join intro call · early SME POV |
| Diligence | join DD team · deep SME POV · comments |
| DD Report | score react · convict / dissent |
| Decision | vote · check-in · pass-with-reason |
| Memo | share · save · thesis tag |

→ writes to **📜 Decisions Ledger** → re-weights routing on next cycle

### ⭐ V1 Activation Surfaces — Where Members Live &nbsp;·&nbsp; **[🔨 Build · V1]**

**★ Social Deal Card — CENTERPIECE.** One persistent card per active deal across all 7 stages. Deal essentials · *why this landed in your feed* · who's engaged · one-tap actions (I'm in / ping me / I know this founder / I know this space) · threaded SME POVs · agent analytical sections inline. Replaces "check the pipeline every two weeks."

**📰 Activity Newsfeed.** Landing surface when a member logs in. Personalized by sector / geo / portfolio. Deal activity · portfolio updates · events · milestones · support exchange. Not a chronological firehose.

**🔎 Directory + Network Agent.** Faceted search over the member graph + NL queries. *"Who knows X?" "Who's in NYC next week?"* Two-hop intro paths. Travel + geography flags.

**👤 Member Profile + Expertise Graph.** Owner-editable + system-derived. Role · firm · expertise tags · prior employers · investment preferences · per-field privacy. Co-investment graph · decisions-ledger track record · expertise centrality. The foundation that makes 200 members visible and routable.

## ⑤ Non-Negotiable Investing Criteria

**TechGroup Hard Pass criteria. Any single failure = Kill.** &nbsp;·&nbsp; **[✓ Live · encoded in V1 Policy Layer]**

Each group contributes its domain-equivalent set when its playbook is built (V2 rollout).

| Criterion | Standard | Scope |
|---|---|---|
| 📄 **Deal Structure** | Equity. Priced round (Seed–Series A). No SAFEs. Convertible debt OK. C-Corp only. | Group-specific |
| 🇺🇸 **Geography** | US-based HQ & IP. Executive team US-based. No foreign-owned entities. | Likely shared |
| 💰 **Traction** | Real revenue or signed paying customers. No research projects or demo labs. | Group-specific |
| 🚀 **Stage / TRL** | MVP complete. At least one successful beta. TRL 5+ (GAO scale). | Group-specific |
| 🤝 **Syndication** | Credible lead investor. Clean cap table — no structural red flags. | Likely shared |
| 📈 **Return Potential** | 10× in 5 years minimum. TAM must support a 20×–100× return path. | Likely shared |
